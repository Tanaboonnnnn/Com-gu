# แนวทางภาษาไทยของ ComGu

ภาษาไทยใน ComGu ควรอ่านเหมือน UI ที่เขียนเป็นภาษาไทยตั้งแต่แรก ไม่ใช่ประโยคอังกฤษที่แปลคำต่อคำ

## หลักการ

- ใช้คำสั้นและตรงกับการกระทำ เช่น `เชื่อมต่อ`, `ตัดการเชื่อมต่อ`, `เลือกโฟลเดอร์`, `ลองอีกครั้ง`
- เก็บชื่อผลิตภัณฑ์และคำที่ผู้ใช้ต้องไปหาในหน้าจออื่นตามต้นฉบับ เช่น `ChatGPT`, `Developer mode`, `API key`, `OpenRouter`, `MCP server URL`
- ชื่อ tool, protocol literal, selector, error code, path, URL, ID และข้อมูลที่มาจากผู้ใช้หรือ process ต้องแสดงตามข้อมูลจริง ห้ามแปลหรือดัดแปลง
- ข้อความเตือนเรื่องสิทธิ์ต้องบอกขอบเขตตามจริง โดยเฉพาะ `Run programs` ซึ่งไม่ได้ถูกจำกัดอยู่แค่โฟลเดอร์ที่อนุญาต
- สถานะควรบอกสิ่งที่เกิดขึ้นตอนนี้ เช่น `กำลังเชื่อมต่อ`, `ยังไม่ได้เชื่อมต่อ`, `เชื่อมต่อแล้ว` มากกว่าคำราชการหรือคำนามลอย ๆ
- ใช้คำอังกฤษทับศัพท์เมื่อเป็นศัพท์ที่คนใช้จริงและช่วยให้หาเมนูหรือเอกสารต่อได้ง่าย เช่น `Tunnel`, `connector`, `menu bar`, `tray`

## ขอบเขตการแปล

แปลเฉพาะข้อความ deterministic ที่ ComGu เป็นเจ้าของ ทั้ง Desktop renderer, popup และ control ที่ extension ฉีดเข้า ChatGPT เท่านั้น ห้ามเดิน DOM เพื่อแปลข้อความของ ChatGPT และห้ามแปลข้อความ user/assistant, tool arguments/results, process output หรือรายละเอียด error ที่รับมาจากระบบอื่น

## การเปลี่ยนภาษา

`config.ui.locale` เป็นแหล่งข้อมูลหลักเพียงจุดเดียว Desktop ต้อง rerender ข้อความที่เปิดอยู่ทันทีโดยไม่รีโหลด และต้องไม่เขียนทับ input/textarea/select ที่ผู้ใช้กำลังแก้ไขอยู่ Extension อ่าน locale จาก app/bridge และไม่มี locale preference แยกใน Chrome storage
