# ComGu v2.0.2

นี่คือ release แรกที่เราเผยแพร่ภายใต้ชื่อ **ComGu** เต็มตัว โดยรวมงาน rebrand, ภาษาไทย/อังกฤษ, cross-platform packaging และการแก้ Auto Compact ที่เคยมีโอกาสตัด turn ของ ChatGPT กลางงาน

## 2.0.2

### Highlights

- เปลี่ยน visible product branding เป็น **ComGu** ทั้ง desktop app, tray, MCP connector names, Chrome companion extension และ installer โดยยังเก็บ internal compatibility identifiers ที่จำเป็นกับข้อมูล/การ pairing เดิมไว้
- เพิ่ม UI **English / ไทย** สำหรับ desktop และ extension พร้อม live language switching
- เปลี่ยน application/extension artwork เป็น ComGu mascot
- ปรับ Auto Compact ให้เป็น **safe boundary**: เมื่อถึง threshold ระหว่าง live turn ระบบจะ arm ไว้ แต่ไม่กด Stop; จะรอ current answer และ local tool calls จบก่อนจึงเริ่ม Compact & Resume
- Manual Compact & Resume ยังเป็น explicit user action และคง behavior แบบ interrupt ตามที่ผู้ใช้สั่งเอง
- เพิ่ม/ปรับ packaging สำหรับ Windows, macOS และ Linux ทั้ง x64/ARM64 พร้อม target-specific native dependencies, tunnel-client และ ripgrep

### Downloads

- `ComGu-Setup-x64.exe` — Windows x64
- `ComGu-Setup-arm64.exe` — Windows ARM64
- `ComGu-macOS-x64.dmg` — macOS Intel
- `ComGu-macOS-x64.zip` — macOS Intel archive
- `ComGu-macOS-arm64.dmg` — macOS Apple Silicon
- `ComGu-macOS-arm64.zip` — macOS Apple Silicon archive
- `ComGu-Linux-x64.AppImage` — Linux x64 portable
- `ComGu-Linux-x64.deb` — Debian/Ubuntu x64
- `ComGu-Linux-arm64.AppImage` — Linux ARM64 portable
- `ComGu-Linux-arm64.deb` — Debian/Ubuntu ARM64
- `ComGu-Extension.zip` — companion Chrome extension
- `SHA256SUMS.txt` — SHA-256 checksums ของทุก release asset

Release workflow สร้างแต่ละ OS/architecture บน native GitHub-hosted runner ของ target นั้น ไม่ cross-build macOS จาก Windows

### Platform notes

- Windows Desktop automation (`observe`, `computer`) ยังเป็น **Windows-only**
- macOS/Linux expose ComGu Core แต่ไม่ expose Desktop automation
- Linux/Ubuntu แนะนำ `.deb` สำหรับการติดตั้งปกติ; AppImage เหมาะกับ portable use
- AppImage ใช้ static launcher; ถ้า host ปิด **unprivileged user namespaces** อาจ fallback ไปเปิด Chromium ด้วย `--no-sandbox` จึงแนะนำ `.deb` บนระบบที่จำกัด sandbox
- Release binaries ยัง **unsigned** และ macOS artifacts ยัง **unnotarized** จึงอาจมี OS trust warning
- macOS ต้องการ **macOS 12 Monterey or newer**

### Upgrade note

หลังอัปเดต desktop app ให้เข้า `chrome://extensions` แล้วกด **Reload** ที่ ComGu companion extension เพื่อให้ app และ extension ใช้ version/runtime ชุดเดียวกัน

### Safety

ComGu มีสิทธิ์รันคำสั่งและเข้าถึง approved folders ตาม permission ที่ผู้ใช้เปิดไว้ ควรตรวจ Home permission panel ก่อนเชื่อม ChatGPT และหลีกเลี่ยงการ approve filesystem root หรือ user profile ทั้งก้อนโดยไม่จำเป็น

> ComGu v2.0.2 ยังเป็น beta สำหรับใช้งานในกลุ่ม และ browser-side integration อาจต้องปรับตามการเปลี่ยนแปลงของ ChatGPT web UI
