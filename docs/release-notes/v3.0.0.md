# ComGu v3.0.0

## 3.0.0

ComGu 3.0 is a major desktop release. It completes the product identity migration, makes Thai a first-class live UI language, adds safer multi-agent/browser orchestration, and turns the updater into a verified cross-platform flow for Windows, macOS and Linux.

### Highlights

- **ComGu identity and migration:** desktop/package/installer identity now uses ComGu. Existing legacy Chat On Steroids config and encrypted secrets are migrated copy-first without deleting the legacy data.
- **Full Thai desktop + companion UI:** app-owned deterministic UI can switch live between English and natural Thai without translating user/tool/process data, paths, IDs, MCP names or protocol literals.
- **Cross-platform verified updater:** update checks now select the exact Windows EXE, macOS DMG, Linux DEB or AppImage for the current host/package form. Downloads are matched exactly and SHA-256 verified before launch. Updates remain explicit: ComGu checks in the background but never downloads or installs without user confirmation.
- **Windows launch at login:** Setup can read and control the real OS login-item state.
- **Browser affinity:** workers, revival, Compact & Resume and prime wake preserve the proven Brave/Chrome/Edge/Chromium family. Explicit browser choices fail closed instead of silently crossing families.
- **Prime auto-wake:** durable worker reports can wake the exact idle prime conversation once, with coalescing while busy and no wake loop.
- **Safer ChatGPT integration:** native approval controls remain authoritative, hidden-tab terminal Fiber scans refresh correctly, and regression coverage was expanded around orchestration and transcript behavior.
- **Native CI:** Windows x64, Linux x64 and macOS arm64 verification run on GitHub-hosted native runners; release packaging additionally produces Windows ARM64 and Linux ARM64 artifacts.

### Platform notes

- Windows Desktop automation (`observe`, `computer`) remains **Windows-only**. macOS/Linux provide ComGu Core without Windows desktop automation.
- macOS 3.0 ships for **Apple Silicon (arm64)** only. The macOS artifacts are currently publisher-**unsigned** and **unnotarized**, so Gatekeeper may show a trust warning.
- Linux users should prefer the `.deb` on Debian/Ubuntu for normal installation. AppImage remains the portable option and may use the documented Chromium `--no-sandbox` fallback on hosts where unprivileged user namespaces are unavailable.

### Upgrade note

After updating the desktop app, reload the ComGu companion extension so the app and browser side use the same release/runtime. The v3 desktop performs copy-first legacy data migration; it does not automatically delete the old Chat On Steroids data.

### Safety

ComGu can run commands and access approved folders only through the permissions you enable. Review the Home permission panel before connecting ChatGPT and avoid approving an entire filesystem root or user profile unless that access is actually required.
