# ComGu v3.0.1

## 3.0.1

This patch repairs two Windows regressions introduced by the 3.0.0 identity migration: side-by-side installation and secure credential decryption.

### Fixes

- **Upgrade in place:** the Windows installer now reuses the v2.x NSIS upgrade GUID instead of deriving a new one from the renamed appId.
- **3.0.0 cleanup:** if the short-lived broken 3.0.0 installer identity is present, setup invokes that exact uninstaller before continuing; app data is retained.
- **Credential continuity:** upgraded users keep the original Electron userData directory before safeStorage starts, so `Local State` and `secrets.bin` remain paired with the same Windows DPAPI-protected key.
- **Clean installs stay clean:** machines without real legacy userData continue to use the normal ComGu directory.
- **Clearer errors:** unreadable encrypted credentials are distinguished from unavailable OS secure storage. The encrypted file is never overwritten on an ambiguous failure.
- **Localization boundary:** app-owned credential error toasts follow the selected language; raw Activity/security diagnostics remain untranslated for debugging.
