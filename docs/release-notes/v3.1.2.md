# ComGu v3.1.2

ComGu 3.1.2 เน้นแก้บัคฝั่ง ChatGPT companion/Workspace, ทำให้ Overwrite อยู่ร่วมกับปุ่ม Copy และไฟล์ดาวน์โหลดของ ChatGPT ได้ดีขึ้น และลดขนาดแพ็กเกจโดยไม่ลดความปลอดภัยหรือความสามารถข้ามแพลตฟอร์ม

## 3.1.2

### จุดเปลี่ยนหลัก

- Extension สามารถตามเวอร์ชันที่ desktop app materialize ไว้และมีปุ่ม Reload extension โดยตรง ช่วยลดการต้องปิด/เปิด extension เองหลังอัปเดต ComGu
- กรณี ChatGPT content script กับ MV3 service worker คนละเวอร์ชันจะมี recovery path ที่อธิบายได้ แทนการปล่อย `unknown_message` ดิบให้ผู้ใช้
- Overwrite mode ไม่ซ่อน ChatGPT-native Copy controls, generated-file links หรือ blob/download links อีกต่อไป จึงไม่ต้องปิด Overwrite เพื่อคัดลอกโค้ดหรือโหลดไฟล์
- การแพ็กเกจ native runtime เลือกเฉพาะ architecture ของ target สำหรับ MXC และตัด PDB/compile-source payload ที่ไม่จำเป็นของ node-pty/tree-sitter ออก โดยยังคง broad ASAR unpack สำหรับ native package ที่ไวต่อ startup หลัง benchmark พบว่า narrow unpack ทำให้เปิดแอปช้าลง
- benchmark Windows x64 ของรอบนี้วัด installer จากประมาณ 157.56 MiB เหลือ 148.40 MiB และ unpacked จาก 543.50 MiB เหลือ 493.08 MiB
- ComGu ยังคงใช้ exact-search stack เดิม: `find` เมื่อ command execution ปิด และ bundled `rg` ผ่าน `exec_command` เมื่อเปิด command execution; zvec Smart Search ไม่ได้รวมอยู่ใน release นี้
- Windows UI Automation helper ให้เวลา `find_ui` สูงสุด 15 วินาที เพื่อไม่ตัด helper ที่ยังทำงานปกติบน hosted runner ที่ช้าเกินขอบ 8 วินาทีเล็กน้อย โดย metadata calls ที่ควรเร็วไม่ได้ถูกผ่อน timeout ตามไปด้วย

### ความปลอดภัยและความเข้ากันได้

- MXC command confinement, WorkspaceScope, path virtualization, permission gates และ fail-closed behavior ยังเหมือนเดิม
- รองรับ release targets เดิมครบ: Windows x64, Windows ARM64, macOS ARM64, Linux x64 และ Linux ARM64
- macOS/Linux ยังไม่มี Run command-confinement backend ที่พิสูจน์แล้ว ดังนั้น Run-scoped commands จะ fail closed ส่วน File WorkspaceScope ยังทำงานตามปกติ
- macOS artifacts ยังเป็น **unsigned** และ **unnotarized**; Gatekeeper อาจเตือนตอนเปิดครั้งแรก

### ดาวน์โหลด

- `ComGu-Setup-x64.exe`: Windows x64
- `ComGu-Setup-arm64.exe`: Windows ARM64
- `ComGu-macOS-arm64.dmg`: macOS Apple Silicon
- `ComGu-macOS-arm64.zip`: macOS Apple Silicon แบบ ZIP
- `ComGu-Linux-x64.AppImage`: Linux x64 แบบพกพา
- `ComGu-Linux-x64.deb`: Debian/Ubuntu x64
- `ComGu-Linux-arm64.AppImage`: Linux ARM64 แบบพกพา
- `ComGu-Linux-arm64.deb`: Debian/Ubuntu ARM64

- `SHA256SUMS.txt`: SHA-256 checksums ของไฟล์ทั้งหมดใน Release

### ติดตั้งบน macOS

ComGu v3.1.2 สำหรับ macOS รองรับ Apple Silicon และต้องใช้ macOS 12 Monterey หรือใหม่กว่า ตัว release นี้ยังไม่ได้ sign ด้วย Apple Developer ID และยังไม่ผ่าน notarization

1. ดาวน์โหลด `ComGu-macOS-arm64.dmg`
2. เปิด DMG แล้วลาก `ComGu.app` ไปที่ `Applications`
3. ถ้า macOS ขึ้นว่าแอปเปิดไม่ได้หรือ damaged ให้เปิด Terminal แล้วรันหนึ่งครั้ง:

```bash
xattr -dr com.apple.quarantine /Applications/ComGu.app && open /Applications/ComGu.app
```

ใช้วิธีนี้เฉพาะกับ ComGu ที่ดาวน์โหลดจาก GitHub Release ของ `Tanaboonnnnn/Com-gu` เท่านั้น

> ComGu v3.1.2 ยังเป็น beta สำหรับ browser-side integration และควรใช้กับงานที่มี version control หรือ backup เสมอ
