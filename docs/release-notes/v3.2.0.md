# ComGu v3.2.0

## 3.2.0

ComGu 3.2.0 is the durable multi-machine runtime release.

## Highlights

- Standalone ComGu CLI for Windows x64/ARM64 and Linux x64/ARM64.
- One profile ownership authority shared by Desktop and CLI, preventing two runtimes from mutating the same profile concurrently.
- Stable machine identity and machine-attributed MCP results for multi-machine routing.
- Durable Run + Checkpoint + Recovery for long-running goals across ChatGPT turn boundaries, reconnects and app restarts.
- Linux Desktop support through X11 and capability-gated Wayland adapters.
- Explicit DesktopDriver lifecycle ownership across connect, reconnect, startup failure and shutdown.
- Desktop permission OFF↔ON changes rebuild the connection/driver generation so model-facing capability, MCP registration and the active adapter stay in sync; Wayland portal revocation invalidates the live capability snapshot.
- `comgu doctor --repair-ownership` safely repairs a stale recovery-election marker after verifying no live endpoint/owner/recovery contender remains.

## CLI downloads

- Windows x64: `ComGu-CLI-windows-x64.zip`
- Windows ARM64: `ComGu-CLI-windows-arm64.zip`

- Linux ARM64: `ComGu-CLI-linux-arm64.tar.gz`

CLI packages require Node.js 22 or newer. Run `comgu.cmd` on Windows or `./comgu` on Linux after extraction.

### One-command install

```sh
npm install -g comgu-cli
```

Linux:

```sh
curl -fsSL https://github.com/Tanaboonnnnn/Com-gu/releases/latest/download/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/Tanaboonnnnn/Com-gu/releases/latest/download/install.ps1 | iex
```

All three channels resolve to the same GitHub Release CLI payload and verify that payload against `SHA256SUMS.txt` before activation.

## Safety model

- Ambiguous mutations are not automatically replayed after transport loss; they enter `needs-reconciliation` until the outcome is proven.
- Machine/config/credential initialization occurs only after profile ownership is acquired.
- Wayland pixel-coordinate actions require a current authoritative frame. Keyboard-only operation can remain available when the portal grants it.
- Semantic desktop refs such as `click_ref` remain usable for app/sidebar navigation without a screenshot frame because they do not consume pixel coordinates.
- Existing WorkspaceScope, terminal ownership, caller identity and fail-closed command-confinement boundaries remain in force.

## Release note

Automated CI covers Windows x64, macOS arm64 and Linux x64 for this PR, and the release workflow contains native package matrices for Windows x64/ARM64, macOS arm64 and Linux x64/ARM64. Real Linux graphical-session RC, especially multi-monitor Wayland behavior, remains a release-promotion check and must not be inferred from deterministic adapter tests alone.

Release binaries remain publisher-**unsigned**, and macOS artifacts remain **unnotarized**. Verify `SHA256SUMS.txt` before installing release assets.
