# ComGu v3.3.0

## 3.3.0

ComGu 3.3.0 simplifies folder authority: the Home folder list is now the single user-facing place to decide which approved roots ComGu may use.

## Highlights

- Each approved folder has a persistent ON/OFF toggle in Home.
- ON folders are directly available to ordinary file and command tools without requiring a chat-bound workspace selection.
- OFF folders fail closed for both virtual and native path spelling.
- Missing or unrecoverable ChatGPT conversation identity no longer blocks ordinary access to folders the user already enabled.
- New approved folders start enabled, while existing 3.2.x roots migrate compatibly with a missing `enabled` field treated as ON.
- Active Runs snapshot the enabled-folder ceiling automatically; workers may narrow that scope but cannot widen into an OFF root.
- The retired Primary/Shared and pending-chat workspace picker UI has been removed.
- Windows command confinement, caller identity, pairing, terminal ownership, durable Run recovery and Wayland frame authority remain enforced.

CLI packages require Node.js 22 or newer.

### One-command install

```sh
npm install -g comgu-cli
```

Linux:

```sh
curl -fsSL https://github.com/Tanaboonnnnn/Com-gu/releases/latest/download/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/Tanaboonnnnn/Com-gu/releases/latest/download/install.ps1 | iex
```

All install channels verify the GitHub Release CLI payload against `SHA256SUMS.txt` before activation.

## Safety model

- Folder toggles are authorization state in the main process, not merely renderer filtering.
- Chat identity remains useful for recording, attribution and orchestration, but it does not grant filesystem roots.
- Active Run and worker scope can only narrow the enabled-root ceiling.
- Windows Run-scoped command processes remain confined by the existing OS sandbox and fail closed when confinement cannot be proven.
- Semantic Desktop refs such as `click_ref` remain frame-free; raw pixel-coordinate actions still require a current authoritative frame.

## Release note

Automated CI covers Windows x64, macOS arm64 and Linux x64, while the release workflow packages Windows x64/ARM64, macOS arm64 and Linux x64/ARM64. Real graphical Linux validation on GNOME/KDE X11/Wayland, especially multi-monitor Wayland coordinate authority, has not been performed in this environment and is not implied by automated adapter/Xvfb tests.

Release binaries remain publisher-**unsigned**, and macOS artifacts remain **unnotarized**. On macOS, use the documented manual Gatekeeper override only for artifacts downloaded from the official ComGu GitHub Release, and verify `SHA256SUMS.txt` before installing.
