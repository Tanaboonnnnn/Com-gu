# ComGu v3.3.3

## 3.3.3

This release persists independent Core and Desktop MCP URL bearer secrets across restarts. A missing or corrupt existing credentials file must be handled carefully: corrupt files fail closed instead of silently rotating credentials. The local MCP listener stays loopback-only; a public Gemini endpoint still requires a separately configured HTTPS tunnel.

## CLI install

```sh
npm install -g comgu-cli
```

Linux one-line installer:

```sh
curl -fsSL https://github.com/Tanaboonnnnn/Com-gu/releases/latest/download/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/Tanaboonnnnn/Com-gu/releases/latest/download/install.ps1 | iex
```

- Local MCP remains loopback-only and bearer-secret protected. A public Gemini endpoint still needs a separately configured HTTPS tunnel.
- macOS artifacts are unsigned and unnotarized.
