# ComGu v3.3.4

This patch release focuses on reliability across the Desktop app, browser companion and standalone CLI.

## Changes

- Preserve the chat's current folder when a Run ends or pauses, and keep newer Run state when pending writes overlap.
- Clear the previous transcript when switching sessions, retry a failed handoff load, and keep history pagination consistent after retention.
- Split oversized browser journal batches until they can be delivered, and keep compaction notices from double-counting dropped observations.
- Correct text encoding and permission descriptions. Keep bundled ripgrep discoverable in POSIX login shells.
- Prevent incomplete CLI installs from becoming active, keep npm payloads separated by architecture, and improve update failure reporting.
- Stream Desktop updater downloads and checksum verification. Failed downloads leave the previously verified installer in place.

## Distribution

Desktop: Windows x64/arm64, Linux x64/arm64, macOS arm64. Standalone CLI: Windows and Linux x64/arm64. The Chrome companion extension is also available separately. Verify downloads with `SHA256SUMS.txt`. Desktop binaries remain publisher-unsigned; macOS builds remain unnotarized.
