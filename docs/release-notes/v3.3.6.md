# ComGu v3.3.6

## 3.3.6

This release adds a read-only status check for an owned terminal command. For a live command started with verified chat ownership, `exec_command` may return a `status_handle`. From the same authenticated chat, pass that handle and the `session_id` to `write_stdin` with `mode: "status"`; omit `chars`, `yield_time_ms`, and `max_output_tokens`. The request neither sends input nor consumes terminal output.

Only the same verified chat and, when applicable, the same Run/workspace scope can query that command generation. Unattributed chats, including connector calls without verified conversation identity, cannot use status mode. Unknown does not prove exit. Standard `write_stdin` input and polling remain unchanged.

## Distribution

Desktop: Windows x64/arm64, Linux x64/arm64, macOS arm64. Standalone CLI: Windows and Linux x64/arm64. The Chrome companion extension is also available separately. Verify downloads with `SHA256SUMS.txt`. Desktop binaries remain publisher-unsigned; macOS builds remain unnotarized.
