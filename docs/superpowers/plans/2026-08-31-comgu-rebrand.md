# ComGu Rebrand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace all user-visible Chat On Steroids branding with ComGu and ship the supplied mascot as the application and extension icon without breaking existing protocol/storage compatibility.

**Architecture:** Treat branding as a presentation/package contract layered over stable internals. Change visible strings, connector display names, package metadata, artifact filenames, and icon source/output while preserving `CLF_*`, bridge identity, storage paths, and other compatibility identifiers.

**Tech Stack:** Electron, TypeScript, JavaScript, Chrome Extension MV3, electron-builder, Vitest, Node.js icon pipeline.

**Spec:** `docs/superpowers/specs/2026-08-31-comgu-rebrand-design.md`

## Global Constraints

- Implementation was performed without git mutation until the user explicitly approved publishing; release integration is handled separately.
- Work only inside `/steroids` for implementation artifacts.
- Preserve `CLF_*`, bridge `app: 'chat-on-steroids'`, storage/data directory identifiers, protocol semantics, durable fingerprints, and internal virtual-path compatibility.
- Product/app/window/tray visible name is `ComGu`.
- Connector display names are `ComGu Core` and `ComGu Desktop`.
- Extension visible name is `ComGu companion` and action title is `ComGu`.
- Use the supplied mascot as `artwork/comgu-logo.jpg`; do not generate a replacement image.
